# X Media Search Button

Xのプロフィールページに「メディア検索」ボタンを追加するChrome拡張機能です。

ワンクリックでそのユーザーの画像・動画付きツイートを検索できます。

## 機能

- プロフィールページに「メディア検索」リンクを表示
- クリックすると `from:ユーザー名 filter:media` で検索
- x.com / twitter.com 両方に対応

## インストール方法

1. このリポジトリをダウンロード
   - 「Code」→「Download ZIP」をクリック
   - または `git clone https://github.com/gfonius/X-Media-Search-Button.git`

2. ZIPの場合は解凍

3. Chromeで `chrome://extensions/` を開く

4. 右上の「デベロッパーモード」をONにする

5. 「パッケージ化されていない拡張機能を読み込む」をクリック

6. ダウンロードしたフォルダを選択

## 使い方

1. X（Twitter）で任意のユーザーのプロフィールページを開く
2. ユーザー名の下に「メディア検索」リンクが表示される
3. クリックすると、そのユーザーのメディア付きツイートが検索される
